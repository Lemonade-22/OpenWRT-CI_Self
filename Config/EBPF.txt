# 共享的非 MT7621 配置：内核 eBPF 支持。
#
# 这一份服务所有 eBPF 透明代理（daed / dae / honk），不是某一个专属：
#   * 内核侧：BTF、cgroup v2、kprobes、BPF syscall/JIT、BPF events、XDP sockets
#   * 模块侧：kmod-sched-bpf、kmod-veth、kmod-nft-queue、nft-tproxy
#
# honk 另需 TCX（NET_CLS_ACT + NET_XGRESS），那两个是隐藏选项，直接写 .config
# 会被 defconfig 静默丢弃，所以由 Scripts/kernel_compat.py 在构建时注册进
# config/Config-kernel.in 后再开。固件内核必须带 TCX，外装 honk 才挂得上。
#
# 固件不内置任何后端本体（daed / dae / honk / luci-app-*），
# 用户按需自行安装，包依赖由 opkg 自己解决。
#
# 内核侧要求：
#   daed  https://github.com/kenzok8/openwrt-daede
#   honk  https://kenzok8.github.io/openwrt-honk/build-firmware.html
