# Aliyun AP8220, 1 GiB NAND (MT29F8G08ABBCAH4, 4096-byte page / 256-KiB eraseblock).
# 单分区变体：NAND 由 MIBIB 描述成「一个 rootfs 分区，覆盖整片 1 GiB」，
# 内核 DTB 使用上游的 qcom,smem-part，不再写死 QWRT / ubi_kernel。
# 刷机前 MIBIB 必须是单分区版本，否则内核找不到 MTD。
#
# WIFI-YES：不关任何无线包，ath11k 驱动来自 target DEFAULT_PACKAGES。
# firmware 包既不在 DEFAULT_PACKAGES 也不在设备包（aliyun_ap8220 只带 ipq-wifi BDF），
# 缺了它只有驱动没有固件，射频起不来，所以这里显式选上。
CONFIG_PACKAGE_ath11k-firmware-ipq8074=y
CONFIG_TARGET_qualcommax=y
CONFIG_TARGET_qualcommax_ipq807x=y
CONFIG_TARGET_DEVICE_qualcommax_ipq807x_DEVICE_aliyun_ap8220=y
